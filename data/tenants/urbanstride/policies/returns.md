# UrbanStride Return & Exchange Policy

- 15-day return window from date of delivery for footwear and bags, unworn with tags attached.
- Footwear must be tried on indoors on a clean surface; shoes returned with worn/scuffed soles will not be accepted.
- Exchanges for a different size are free (one exchange per order). Refunds for change-of-mind are issued as store credit, not original payment method.
- Defective items are eligible for a full refund to original payment method, no time limit within the 1-year warranty period.
